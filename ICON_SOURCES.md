# Icon sources

All the situation icons are Google Material Icons (filled style), added with
Android Studio's Vector Asset tool.

- Source: https://fonts.google.com/icons and https://github.com/google/material-design-icons
- Licence: Apache License 2.0, which allows them to be used and changed in apps as long as
  the licence is credited. Only the tint colour was changed.

| Drawable | Material icon | Used for |
|---|---|---|
| `ic_road_closed` | block | Incident: road closed |
| `ic_accident` | car_crash | Incident: accident |
| `ic_queue` | directions_car | Incident: queuing traffic (AbnormalTraffic) |
| `ic_incident_other` | warning | Incident: anything else (obstructions, lane management...) |
| `ic_temp_lights` | traffic | Roadworks: temporary traffic lights / stop and go / convoy |
| `ic_lane_closure` | call_merge | Roadworks: lane, hard shoulder or mobile lane closures |
| `ic_road_closure_works` | do_not_disturb_on | Roadworks: road / slip / layby closures, diversions |
| `ic_speed_restriction` | speed | Roadworks: speed restrictions |
| `ic_roadworks` | construction | Roadworks: everything else (verge works, signage...) |
